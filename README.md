# دليل المربي — منهج بناء الفتى المسلم

موقع تفاعلي للمعلم أثناء التحضير وشرح الدروس: 5 وحدات، و25 لقاءً، وكل لقاء وفق نموذج الـ 16 محوراً.

## المزايا
- تصميم مناسب للجوال، عربي بالكامل (RTL) بخط Tajawal.
- الآيات والأحاديث ظاهرة كاملة، والمصادر والاقتباسات في قوائم منسدلة.
- وضع العرض، ومؤقت الحصة، وبنك الأسئلة التفاعلي، وبطاقات الطلاب القابلة للطباعة.
- تصدير أي لقاء كملف سلايدات PowerPoint: «سلايدات المربي» (تفصيلية)، و«سلايدات الطلاب» (مرئية بمخططات وتأثيرات ظهور تدريجي لعرضها أمام الطلاب).
- بحث في كل اللقاءات، ووضع فاتح وداكن.

## التشغيل
افتح `index.html` مباشرة، أو فعّل GitHub Pages من إعدادات المستودع (Branch: `main`، المجلد: `/root`).
